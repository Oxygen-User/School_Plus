# School_Plus

This project is made to test infrastructure and interface for another Gamification project.

This includes
- Main menu
- Language (localization) changer
- Switching between menus
- Tried to go for a more natural background but it needs to be polished and it doesn't look good right now.
- Biology menu
    - In this menu you can view the effects of auxin hormone's effect on plants
    - And mess with sliders to see how the plant or distribution of auxin changes
- Math menu
    - this menu has just been added and just has a link opener 

  Made for [Terra](https://terra.hackclub.com/r/F7S2)

Got some of the assets from [here](https://assetstore.unity.com/packages/2d/gui/icons/simple-button-set-01-153979)


## How to Open

There are 2 ways to open this project:

### 1

You can open the project from your web browser using this [Link]() (Press ESC to stop the project when opened this way)

### 2

Download this whole repository and view the project altogether on unity editor.

---

## How to Play/Use


- Press Start button to go to the start menu
- Check out the language button on the top right corner and pick your language. (Just learned this feature, it took some time)
- Click on biology or math symbols to view their subjects (There is currently one)
- First slider in Auxin shows the distribution of auxin according to light source
- Second slider shows the effect of auxin
- And the third one Shows lack or overdose of auxin (Learned how to manipulate sliders with scripts and how to customize them)
- The button in math section takes to a learning site from Türkiye.
